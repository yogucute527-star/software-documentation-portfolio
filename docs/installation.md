# Installation / Setup

This guide explains how to set up TaskFlow for use.

## System Requirements

Before setting up TaskFlow, make sure you have:

- A supported desktop or mobile device
- A stable internet connection
- A supported web browser
- A valid TaskFlow account

## Accessing TaskFlow

TaskFlow is accessed through a web browser.

1. Open a supported web browser.
2. Go to the TaskFlow application.
3. Sign in using your TaskFlow account.
4. After signing in, the TaskFlow dashboard is displayed.

## Initial Setup

After accessing TaskFlow for the first time:

1. Sign in to your account.
2. Review your account settings.
3. Create your first project.
4. Add tasks to the project.
5. Configure task status and other available project settings.

## Next Steps

After completing the initial setup, see the [Configuration Guide](configuration.md) to learn how to configure TaskFlow for your workflow.
