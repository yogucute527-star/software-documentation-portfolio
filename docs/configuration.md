# Configuration

This guide explains the basic configuration options available in TaskFlow.

## Account Settings

Users can manage their account settings, including:

- Display name
- Email address
- Password
- Notification preferences

## Project Settings

Project owners can configure settings for individual projects.

Available settings may include:

- Project name
- Project description
- Task status options
- Project members
- Notification preferences

## Task Settings

Task settings can be used to organize and manage work within a project.

Users can configure:

- Task status
- Task priority
- Task due date
- Task assignee

## Notification Settings

Users can configure notifications based on their preferences.

Notifications may be available for:

- Task assignments
- Task status changes
- Upcoming due dates
- Project updates
