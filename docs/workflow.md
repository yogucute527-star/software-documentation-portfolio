# Workflow

This guide describes the typical workflow for managing work in TaskFlow.

## Workflow Overview

A typical TaskFlow workflow follows these steps:

1. Create a project.
2. Add tasks to the project.
3. Assign tasks to team members.
4. Set task details and priorities.
5. Work on assigned tasks.
6. Update task status as work progresses.
7. Mark completed tasks as complete.
8. Review overall project progress.

## Step 1: Create a Project

Create a project to organize related work in one place.

Enter the project name and description, then save the project.

## Step 2: Add Tasks

Add tasks to the project and provide the information needed to complete each task.

Task information may include:

- Task title
- Description
- Priority
- Due date
- Assignee

## Step 3: Assign Tasks

Assign each task to the appropriate team member.

The assigned user can then view the task and work on it.

## Step 4: Update Task Status

Update the task status as work progresses.

A typical status flow is:

**Not Started → In Progress → Completed**

Keeping task status up to date helps team members understand current progress.

## Step 5: Complete the Work

When the task is finished, update its status to **Completed**.

Review the task details to make sure the required work has been completed.

## Step 6: Review Project Progress

Review the project's tasks and their current statuses to understand overall progress.

Project owners can use this information to identify completed work, active tasks, and tasks that still need attention.
