# Usage Guide

This guide explains how to use TaskFlow to manage projects and tasks.

## Creating a Project

1. Sign in to TaskFlow.
2. Open the dashboard.
3. Select the option to create a new project.
4. Enter a project name and description.
5. Save the project.

## Adding a Task

1. Open a project.
2. Select the option to add a task.
3. Enter a task title and description.
4. Set the task status, priority, due date, and assignee as needed.
5. Save the task.

## Managing Tasks

After creating a task, users can update its information as work progresses.

Common task actions include:

- Updating the task status
- Changing the task priority
- Updating the due date
- Assigning the task to a user
- Editing the task description

## Tracking Project Progress

Users can review tasks within a project to track progress.

Task status can be used to identify whether work is:

- Not started
- In progress
- Completed

## Managing Projects

Project owners can update project information and manage project members.

Common project actions include:

- Editing project details
- Adding or removing project members
- Reviewing project tasks
- Monitoring task progress
